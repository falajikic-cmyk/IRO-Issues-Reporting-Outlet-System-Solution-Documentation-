# IRO (Issues Reporting Outlet)

## Project Overview
The **Issues Reporting Outlet (IRO)** is a web-based reporting platform designed to facilitate transparent issue management and resolution for Adekunle Ajasin University, Akungba-Akoko (AAUA) students and community indigenes across Akungba, Iwaro, Etioro, and Ayegunle.
